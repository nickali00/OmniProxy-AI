Un solo gateway per le app che usano API AI.

Collega gli account e i modelli supportati a OpenClaw, n8n, backend, automazioni e applicazioni custom tramite un endpoint locale OpenAI-compatible, monitorando richieste, token, latenza e quote.

n8n è l'esempio, non il limite

La demo mostra una API gestita usata da n8n, ma lo stesso Base URL, la stessa chiave locale e lo stesso modello possono essere configurati in qualunque client che accetti un endpoint OpenAI-compatible personalizzato.

OpenClaw n8n Backend Workflow App custom OpenAI-compatible
Installa OmniProxy Release v0.1.0

Compatibilità: l'applicazione deve permettere di configurare un Base URL personalizzato e il protocollo OpenAI Chat Completions. Per software proprietario o interno è possibile integrare direttamente /v1/chat/completions e /v1/models.

Rete: OmniProxy ascolta su 127.0.0.1 per impostazione predefinita. I client remoti devono raggiungerlo tramite VPN privata oppure tramite un reverse proxy HTTPS che esponga soltanto /v1/*. La dashboard e la porta 8000 non devono essere pubblicate direttamente su Internet.
